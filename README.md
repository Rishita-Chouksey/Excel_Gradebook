# Excel Gradebook Management System

## Overview

The Excel Gradebook Management System is a microproject developed during the first semester at MITS Gwalior. The project is designed to automate the process of managing student academic records, calculating marks, generating grade sheets, and preparing final result summaries using Microsoft Excel.

The workbook integrates multiple sheets to maintain student information, subject-wise marks, grading schemes, and consolidated results, reducing manual effort and improving accuracy in academic record management.

---

## Features

* Student information management
* Subject-wise marks entry
* Automated grade calculation
* Result processing and consolidation
* Final marksheet generation
* Semester performance tracking
* Multi-sheet data organization
* Formula-based calculations for accuracy
* Structured academic record management

---

## Workbook Structure

### Student Information

Stores student details and basic academic information.

### Scheme

Contains grading criteria, course structure, and evaluation scheme.

### Subject Sheets

Separate sheets for recording marks of individual subjects.

### Final Sheet

Consolidates performance across all subjects and calculates overall results.

### Marksheet

Generates a complete marksheet containing academic performance details.
